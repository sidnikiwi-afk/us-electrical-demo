# Electrician Planner

A prototype for drawing electrical plans, placing fittings, checking quantities and preparing draft labour quotes.

## Workspace

This is the dedicated local project repository: `/Users/saeed/Projects/electrician-planner`.

- `prototype/`: the app, preserved from release `94d6345`.
- `index.html`: the earlier demonstration page.
- `tests/`: final EP21 test files, copied from the verified evidence archive. Some tests require the Office fixtures and Playwright setup; see the archived verification instructions before running.
- `.private/pilot-archive/`: local copy of the existing pilot material, including handoffs, evidence, earlier demos and tickets. Ignored by Git.
- `.private/requests/`: private WhatsApp request notes. Ignored by Git.
- `docs/WORKSPACE.md`: migration and operating context.

Git history and the pre-update rollback point are preserved. The existing GitHub remote is retained; this workspace setup does not create a new online repository or publish changes.
