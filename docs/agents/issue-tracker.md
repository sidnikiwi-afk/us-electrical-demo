# Issue tracker

Approved local Markdown tracker for the floor-zones build: `.scratch/floor-zones/issues/`, one ticket per file with explicit blocking edges. Spec: `.scratch/floor-zones/SPEC.md`. Controller owns statuses and detailed handoff comments; workers return results only. The local-deliverable status does not mean PR merged or published. Integration/review/release is tracked by ticket 07. No external issue creation is needed.
